# Course Registration System

Course Registration System is a full-stack web application built using **Java Spring Boot**, **HTML**, **CSS**, and **JavaScript**. It allows students to register for courses, stores data in a database, and dynamically displays enrolled student counts and available courses via REST APIs. :contentReference[oaicite:0]{index=0}

## 🛠️ Features

- 📥 **Course Registration** – Students can register for available courses.
- 🗄️ **Database Integration** – Registrations and course details are stored in a database.
- 📊 **Dynamic Display** – View number of students enrolled and available courses.
- 🔁 **Client–Server Communication** – Frontend interacts with backend via REST APIs.

## 🧱 Tech Stack

- **Backend:** Java Spring Boot  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** MySQL  
- **Build Tool:** Maven
